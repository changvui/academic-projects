# Brain tumour MRI classification

Coursework project for **Artificial Intelligence**. The task: classify brain MRI scans into
four classes — glioma, meningioma, pituitary tumour, and no tumour — and ship a small app
that can be demonstrated.

## Models

| Model | Folder | Author |
|-------|--------|--------|
| SegFormer-B0 (fine-tuned) | `SegFormer_Tiong/` | Tiong Chang Vui |
| ResNet-50 (baseline) | `ResNet-50_Kerry/` | Wong Kai Lit Kerry |

## What I did (SegFormer)

- Loaded `nvidia/segformer-b0-finetuned-ade-512-512` and replaced the head for 4-class
  classification
- Built a PyTorch `Dataset` around the MRI images with the 224 px SegFormer processor
- Trained with Hugging Face `Trainer`: 5 epochs, learning rate 3e-5, batch size 16
- Evaluated on the dataset's test split with per-class precision, recall and F1, plus a
  confusion matrix, rather than relying on one accuracy number
- Wrapped inference in a Streamlit app with class probabilities and a short description of
  each class

## Files

- `SegFormer_Tiong/*.ipynb` — training and evaluation notebooks
- `Application File/app.py` — Streamlit demo
- `Application File/examples/` — sample predictions and the confusion matrix
